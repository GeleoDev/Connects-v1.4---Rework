Descripción del producto

El MAX BR1 Mini es un router celular compacto de Peplink, ideal para sucursales, kioscos y despliegues con poco espacio. Combina conectividad celular con puertos Ethernet (incluyendo PoE IN), Wi-Fi y entrada de alimentación con soporte de ignición, para una instalación simple y confiable.

  • Router celular compacto para espacios reducidos
  • 3x puertos Ethernet (LAN 1 con PoE IN, LAN 2, LAN 3/WAN)
  • Conectividad Wi-Fi y celular integradas
  • Entrada DC con soporte de ignición (IGN I/P)
  • Diseño robusto para entornos exigentes
  • Gestión remota vía InControl2
  • Ideal como conexión primaria o de respaldo
